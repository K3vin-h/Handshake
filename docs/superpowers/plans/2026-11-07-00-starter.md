# Handshake Starter (H0 → H0.5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the shared foundation on `main` so the three groups can work in parallel: frozen interfaces, a stub file for every new module, every route, and test tooling. All of it done by H0.5.

**Architecture:** This plan only adds types, stubs and plumbing. Every stub compiles and renders something usable, so each group replaces only its own stubs and never touches another group's files. Interfaces follow `docs/superpowers/specs/2026-11-07-handshake-design.md` §4.

**Tech Stack:** React 19 + TypeScript + Vite, Express, Node 24 (`node --test` runs `.ts` files natively).

**Owner:** Ryan, with everyone watching. Group plans: `2026-11-07-group-1-cv.md`, `2026-11-07-group-2-frontend.md`, `2026-11-07-group-3-backend.md`.

## Roadmap (all plans follow it)
Build in curriculum order. Each milestone is a playable slice that all three groups merge and demo together before anyone starts the next one:
**M0 Foundation (this plan, H0.5) → M1 Your name (H6) → M2 Alphabet + their name (H10) → M3 Greetings (H14) → M4 Conversation (H16, freeze) → Ship (H24).**
Each group plan has one section per milestone, ending with a **gate** checklist that's identical across the three plans.

## Global Constraints
- Letter set: `A B C D F I L O V W Y` + handshapes `5`, `H`. No J/Z grading.
- Names never leave the device, except to n8n after explicit opt-in consent (sponsor-tracks spec). Gemini, the planner agent and our database never get names; Gemini gets letters and error codes only.
- Same baseline (spec §2 rule 5): everyone starts at 1.1, no placement or level quiz, same units and unlock rule for everyone.
- UI says "matches the reference", never "correct".
- Gemini key only in `.env`. `npm run build` and `npm test` pass on `main` after every merge.
- Each person edits only their owned files (spec §5). Interface changes need the whole team's agreement.
- Imports inside files under test use explicit `.ts` extensions (`node --test` needs them; Vite accepts them).

// Builds an 88-number feature vector with given curls (thumb..pinky) and directions; everything else 0.
const UP: [number, number] = [0, -1];
function vec(curls: number[], dirs: [number, number][] = [UP, UP, UP, UP, UP]) {
  const f = new Array(88).fill(0);
  curls.forEach((c, i) => (f[63 + i] = c));
  dirs.forEach(([x, y], i) => ((f[68 + i * 2] = x), (f[69 + i * 2] = y)));
  return f;
}

test("curl difference gets a finger:curl code", () => {
  const out = getHandFeedback(vec([0, 0.9, 0, 0, 0]), vec([0, 0, 0, 0, 0]));
  assert.deepEqual(out.map((o) => o.code), ["index:curl"]);
  assert.equal(out[0].finger, "index");
});

test("direction difference on an extended finger gets finger:direction", () => {

import type { Personalization } from "./curriculum";

// The learner profile lives ONLY in this browser. Names never go to the server.
// Onboarding asks names + signing hand only; everyone starts at lesson 1.1.
export type Profile = Personalization & { leftHanded: boolean };

/** Home welcome line, same for everyone; names are filled in on the device with fillNames(). */
export const WELCOME = "Let's start with your name, {you}. In a few lessons you'll be saying hello to {them}.";

const KEY = "handshake.profile.v1";
let memory: Profile | null = null; // fallback when localStorage is blocked

export const DEMO_PROFILE: Profile = {
  userName: "Ryan",
  theirName: "Lily",
  leftHanded: false,
};

export function loadProfile(): Profile | null {
  try {
    const s = localStorage.getItem(KEY);
    return s ? JSON.parse(s) : memory;
  } catch {
    return memory;
  }
}

export function saveProfile(p: Profile) {
  memory = p;
  try {
    localStorage.setItem(KEY, JSON.stringify(p));
  } catch {
    /* session only */
  }
}

/** Fills {you}/{them} on the device. */
export const fillNames = (text: string, p: Pick<Profile, "userName" | "theirName">) =>
  text.replaceAll("{you}", p.userName).replaceAll("{them}", p.theirName);

/** A lesson is unlocked when the previous DEMO lesson (in path order) is completed. Stretch lessons never gate. */
export function isUnlocked(units: Unit[], p: Progress, lessonId: string): boolean {
  const all = flatLessons(units);
  const i = all.findIndex((l) => l.id === lessonId);
  const prev = all.slice(0, Math.max(0, i)).filter((l) => l.scope === "demo").at(-1);
  return !prev || p.completed.includes(prev.id);
}

/** Next lesson to do (first demo lesson not completed). */
export function nextLesson(units: Unit[], p: Progress) {
  return flatLessons(units).find((l) => l.scope === "demo" && !p.completed.includes(l.id)) ?? null;
}

- [ ] **Step 7: Router in `src/App.tsx` (replace the whole file)**

```tsx
import { useEffect, useState, type ReactElement } from "react";
import { LessonDemo } from "./screens/LessonDemo";
import { RecordPage } from "./screens/RecordPage";
import { CurriculumPreview } from "./screens/CurriculumPreview";
import { Home } from "./screens/Home";
import { Onboarding } from "./screens/Onboarding";
import { LessonPlayer } from "./screens/LessonPlayer";
import { Complete } from "./screens/Complete";
import { ProgressScreen } from "./screens/Progress";
import { LessonPreview } from "./screens/LessonPreview";
import { loadProfile } from "./lib/profile";

// Hash router: "#/lesson/1.1" → name "lesson", param "1.1".
// Dev tools (record, curriculum, demo) work without a profile; everything else needs onboarding first.
function screen(hash: string): ReactElement {
  const [, name = "", param = ""] = hash.split("/");
  if (name === "record") return <RecordPage />;
  if (name === "curriculum") return <CurriculumPreview />;
  if (name === "demo") return <LessonDemo />;
  if (name === "lesson-preview") return <LessonPreview />;
  if (name === "welcome" || !loadProfile()) return <Onboarding />;
  if (name === "lesson") return <LessonPlayer key={param} lessonId={param} />;
  if (name === "complete") return <Complete lessonId={param} />;
  if (name === "progress") return <ProgressScreen />;
  return <Home />;
}

export default function App() {
  const [hash, setHash] = useState(location.hash || "#/");
  useEffect(() => {
    const on = () => setHash(location.hash || "#/");
    addEventListener("hashchange", on);
    return () => removeEventListener("hashchange", on);
  }, []);
  return (
    <>
      <nav>
        <b>Handshake</b>
        <a href="#/">Path</a>
        <a href="#/progress">Progress</a>
        <a href="#/demo">Demo</a>
        <a href="#/record">Record</a>
        <a href="#/curriculum">Curriculum</a>
      </nav>
      {screen(hash)}
    </>
  );
}
```
