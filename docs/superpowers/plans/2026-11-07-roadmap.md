# Handshake Roadmap

The single page that shows the **entire scope**: what gets built, in what order, by whom, and what "done" means at each step.
Spec: `docs/superpowers/specs/2026-11-07-handshake-design.md`. Plans: `2026-11-07-00-starter.md`, `2026-11-07-group-1-cv.md`, `2026-11-07-group-2-frontend.md`, `2026-11-07-group-3-backend.md`.

## How it works
- **Same baseline, Duolingo-style:** no placement or level quiz. Everyone starts at 1.1 and follows the same units in the same order: introduce yourself → alphabet → greetings and sentences → conversation. Only practice words and review adapt.
- We build **in curriculum order**: your name → the alphabet + their name → greetings → conversation. Each step is a **milestone**.
- A milestone is a **playable vertical slice**. All three groups build their part, merge to `main`, and play it end to end at the gate (5-minute standup) before anyone starts the next milestone's features.
- Non-feature work (Figma, interviews, Devpost) runs alongside, at the hours shown.
- If a gate fails, apply its **cut rule** and move on. The clock wins.

```
H0 ── M0 Foundation ── H0.5 ── M1 Your name ── H6 ── M2 Alphabet + their name ── H10 ── M3 Greetings ── H14 ── M4 Conversation ── H16 FREEZE ── Ship ── H24
```

**Gate M1:**
- [ ] Onboarding (or demo profile) → Home shows "Introduce yourself" with the learner's name.
- [ ] 1.1 plays with real recognition: learn Y → practise Y ×3 → learn A → practise A ×3 (name order); R and N show "reference only, coming later".
- [ ] A miss shows the landmark tip instantly, then the Gemini tip (or the mock tip without a key).
- [ ] 1.2 and 1.3 spell RYAN, skipping R/N tiles marked reference only.
- [ ] Complete screen shows XP; reload keeps progress.
- [ ] `npm run build && npm test` pass on `main`.

**Cut rule:** if recognition of the name letters isn't reliable, switch the demo profile's name to one built from L I Y B O V letters (e.g. "Bo") and continue.
